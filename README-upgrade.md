Stock One (스탁원) 홈페이지 — 개선된 B2B 템플릿

변경 사항 요약:
- 고급스러운 네이비/화이트 디자인 적용
- 히어로 영역에 강렬한 홍보 문구 배치
- 회사소개, 핵심 경쟁력, 서비스, 작업 현장, 견적 문의 섹션 상세화
- 견적 문의는 assets/config.js 의 FORM_ENDPOINT 설정으로 자동 접수 가능 (미설정 시 버튼 비활성화 및 이메일 안내)

배포 및 이미지 교체 안내:
- 공식 로고가 있으면 저장소에 assets/logo.png 로 업로드하세요. 없으면 텍스트 로고가 표시됩니다.
- 히어로 배경 이미지: assets/hero.jpg (실제 촬영 이미지 또는 고품질 스톡 이미지를 업로드하세요)
- 작업 현장 사진(요청하신 한국인 남성 직원 2명 사진): assets/work-crew.jpg 로 업로드하세요. 현재는 자리표시자입니다.

GitHub Pages로 공개하려면:
1) Settings > Pages 에서 'gh-pages' 브랜치를 선택하고 / (root)로 설정 후 저장하세요.
2) 잠시 후 https://a62992063-afk.github.io/stockone-homepage/ 에서 확인 가능합니다.

자동 접수(실제 견적 접수) 연결 방법 예시:
- Formspree: 폼 엔드포인트를 발급받아 assets/config.js 의 FORM_ENDPOINT에 넣으면 동작합니다.
- 또는 자체 서버의 웹훅(API)를 제공하면 동일하게 사용 가능합니다.

주의:
- 공식 로고 파일이 없으므로 임의 로고 이미지는 생성하지 않았습니다.
- 작업 현장 사진(특정 인종/인물 요구)은 프라이버시와 저작권 문제로 저장소에 임의 이미지를 추가하지 않았습니다. 제공하시면 assets/ 경로에 업로드해 드립니다.
